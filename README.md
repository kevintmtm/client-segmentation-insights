# Customer Segmentation with K-Means

Customer clustering project using K-Means to segment bank clients based on demographic and financial features.

## Project structure
- notebooks/: exploratory analysis and clustering
- docs/: explanatory document

## Main techniques
- One-Hot Encoding / Ordinal Encoding
- RobustScaler
- K-Means clustering
- Elbow Method & Silhouette Score
